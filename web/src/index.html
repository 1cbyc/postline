A content calendar that lives in git

Plan, render and publish branded social posts from a git repo.

Each post is a Markdown file. postline checks it against your house rules, renders an on-brand image card for it, and publishes it to LinkedIn, Bluesky, Mastodon or any webhook when its time comes.

$ npm install --global postline
Get started

One Markdown file in. A branded card and a scheduled post out.

postline render

What you get

  1. Posts as files

    Review copy in pull requests. Grep your history. Nothing is locked in a vendor.

  2. Cards from your design system

    Colours, font and logo live in one file. Point it at your design tokens, add your own CSS, or write your own layouts in HTML.

  3. Rules that block bad posts

    Hashtag limits, banned phrases, allowed link domains, emoji policy, per-network character limits and a check for broken text encoding.

  4. Publishing that never double posts

    Official APIs only. If a run dies mid-send or a network gives no clear answer, postline stops and asks instead of guessing.

  5. Every graphic kept

    A lossless, full-size copy of each card is saved on your computer with a gallery to browse them later.

Your week, at a glance

Drafts for every empty slot with postline plan. Lint them in CI. Then publish from GitHub Actions, your operating system's scheduler, or the built-in daemon on any always-on machine. A ledger records what went where.

How scheduling works

Does every post look the same? Only if you want it to.

  1. Built-in layouts Rows, grid and statement, in your colours, font and logo. Zero setup.
  2. Your tokens and CSS Read the tokens file your design system already exports and restyle the built-in layouts.
  3. Your own layouts Drop HTML templates into a folder; quote.html becomes layout: quote.

Bring your own design system

Where it publishes

LinkedIn
Company pages or members, via the Posts API. Hashtags stay clickable.
Bluesky
App password login. Links and hashtags become rich text, and retries can't post twice.
Mastodon
Any instance, with an idempotency key on every status.
Webhook
A signed JSON POST for Zapier, Make, n8n, Slack approvals or your own service.
Files
Markdown and the image into a folder, such as your static site's blog.
